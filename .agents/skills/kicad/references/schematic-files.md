# Schematic Files

## Format

- KiCad schematic files use a UTF-8, human-readable S-expression format and the `.kicad_sch` extension.
- Use UTF-8 without BOM for `.kicad_sch` files. A valid schematic starts directly with `(kicad_sch`.
- The root token is `(kicad_sch ...)`. It contains a required `(version YYYYMMDD)` token and a `(generator ...)` token.
- KiCad's developer documentation asks third-party writers not to use `eeschema` as the generator identifier. Generated files should use a distinct generator name.
- Coordinates and dimensions are stored in millimeters. Schematic and symbol library data has four decimal places of useful precision.
- `(at X Y [ANGLE])` gives object position and optional rotation. For most objects the angle is in degrees; symbol text angles are stored in tenths of a degree.
- `(pts (xy X Y) ...)` stores ordered point lists for wires, buses, and graphical objects.
- KiCad's public file format docs describe the S-expression schematic format for KiCad 6.0 and newer. Local KiCad 10 files have `(version 20260306)` and `(generator_version "10.0")` when saved by Eeschema.

## Main Elements

| Area | Elements |
| --- | --- |
| Schematic root | `kicad_sch`, `title_block`, `sheet_instances` |
| Shared syntax | `at`, `pts` |
| Symbols and properties | `symbol`, `pin`, `property`, power symbols, reference designators |
| Electrical routing | `wire`, `junction`, `bus`, `bus_entry` |
| Net naming and open pins | `label`, `no_connect` |
| Graphics and annotations | `polyline`, `text`, `image` |
| Hierarchy | `sheet`, labels, sheet instances |
| Organization | `group` |

## Symbols

Symbols are stored in two related forms:

- A library symbol definition inside `(lib_symbols ...)` describes reusable graphics, pins, and default properties.
- A placed schematic symbol appears at schematic level and references a library symbol with `lib_id`.

The top-level library name, for example `"power:GND"` or `"Simulation_SPICE:NMOS"`, must match the placed schematic instance `(lib_id "...")`.

Nested symbol names use KiCad's generated convention for unit and body style:

| Name | Meaning |
| --- | --- |
| `"Name_0_1"` | Common graphics for all units, body style 1 |
| `"Name_1_1"` | Unit 1 graphics and pins, body style 1 |
| `"Name_2_1"` | Unit 2 graphics and pins, body style 1 |

Use unit `0` only for graphics shared by all units. Put electrical pins in a concrete unit section such as `Name_1_1`.

## Properties

Properties are stored as:

```lisp
(property "Name" "Value" ...)
```

They can appear in `lib_symbols` symbol definitions or in placed schematic `symbol` instances.

Common properties:

| Property | Purpose |
| --- | --- |
| `"Reference"` | Symbol reference designator, for example `R1`, `U1`, `#PWR01`, or `#FLG01` |
| `"Value"` | Visible logical value or net name; for power symbols this is the global net |
| `"Footprint"` | PCB footprint library identifier |
| `"Datasheet"` | Datasheet URL or document reference |
| `"Description"` | Human-readable symbol description |
| `"ki_keywords"` | Space-separated search keywords used by KiCad symbol selection |
| `"ki_fp_filters"` | Footprint filters |
| `"Sim.Device"` | SPICE device kind |
| `"Sim.Type"` | SPICE model or primitive type |
| `"Sim.Pins"` | Mapping between KiCad pins and SPICE pins, for example `1=D 2=G 3=S` |

Property fields can include `at`, `show_name`, `do_not_autoplace`, `hide`, and `effects`.

## Placed Symbols

Placed symbols reference a library definition with `lib_id` and provide location, UUIDs, instance properties, and pin UUIDs.

Important fields:

| Field | Purpose |
| --- | --- |
| `lib_id` | Library symbol name from `lib_symbols` |
| `at` | Schematic placement origin and rotation |
| `unit` | Selected unit from the symbol definition |
| `body_style` | Selected body style |
| `exclude_from_sim`, `in_bom`, `on_board`, `in_pos_files`, `dnp` | Instance flags |
| `uuid` | Unique identifier for this placed symbol instance |
| `property` | Instance-specific property values and text positions |
| `pin` | Per-pin UUID record; the pin number must exist in the library symbol |
| `instances` | Project and sheet-path reference data generated by KiCad |

When changing references, update both:

- The placed `property "Reference" "..."`.
- The corresponding instance `(reference "...")`.

Do not change `lib_id` unless the actual symbol library binding changes.
